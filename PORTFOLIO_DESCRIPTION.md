# Portfolio Description

## University Student Data Analyzer

**Tools:** Python, pandas, Matplotlib, CSV

Built a beginner-level data analysis workflow using a fictional university student dataset. The script imports CSV data, checks missing values, calculates overall summary statistics, groups results by department and semester, visualizes average GPA, and exports summary tables and charts.

**Key outputs**
- Overall summary CSV
- Department and semester summary CSVs
- Average GPA charts
- Practice-only review list for records below an explicitly labeled example threshold

**Responsible data use:** The dataset is synthetic. The example threshold is not an official academic policy, and the project is not intended for real student decision-making.

**Current status:** Learning project. Results should be described as completed only after running the script, checking the outputs, and being able to explain the code.
