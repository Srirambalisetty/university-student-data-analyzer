# Interview Notes: Explain Your Project Honestly

Use these prompts to practice explaining the project in your own words. Do not claim tools or steps you have not personally used.

## 30-second explanation
“I built a beginner Python project that analyzes a fictional university student dataset. I used pandas to load the CSV, check for missing values, calculate summary statistics, and group data by department and semester. I used Matplotlib to create GPA charts and exported the results so they could be reviewed in a report.”

## Be ready to explain
1. What is a CSV file?
2. Why did you use pandas?
3. What does `students.isna().sum()` show?
4. What does `groupby("Department")` do?
5. Why use an average, and what are its limitations?
6. What does the chart communicate?
7. Why is the data fictional?
8. Why should a practice GPA threshold not be treated as official policy?
9. What would you improve next?

## Honest status language
- Before running: “I am building and learning this project.”
- After running and checking it: “I built and tested this beginner project using fictional data.”
- If you modify the code: explain which changes you made yourself.

## Possible next steps
SQL querying, stronger data validation, unit tests, and a Power BI dashboard.
